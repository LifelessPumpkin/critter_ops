# Definition of Done

A GitHub Issue is considered complete when all of the following criteria have been met.

## Development

* Feature has been implemented.
* Project builds successfully.
* No compiler warnings introduced without justification.
* Existing functionality has not been broken.

## Verification

* Feature has been manually tested.
* Acceptance criteria from the GitHub Issue have been satisfied.

## Documentation

* Documentation has been updated if required.
* Any new environment variables or setup instructions have been documented.

## Git

* Work exists on its own feature branch.
* Pull Request targets develop.
* GitHub Issue is linked to the Pull Request.

Only after these requirements are satisfied should the issue be marked as complete.
