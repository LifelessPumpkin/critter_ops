# Gilligan Web App

The Next.js frontend application for the CritterOps platform.

## Getting Started

### Prerequisites

Ensure you have Node.js (version 18.0 or later) and `npm` installed.

### Install Dependencies

Navigate to this folder and install dependencies:

```bash
npm install
```

### Run the Development Server

To start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Project Structure

- `src/app/page.tsx`: Main dashboard landing page containing links to backend resources.
- `src/app/layout.tsx`: Root layout shell defining Geist fonts, metadata, and body structure.
- `src/app/globals.css`: Premium dark mode CSS stylesheet containing the design system variables and layout styling.
